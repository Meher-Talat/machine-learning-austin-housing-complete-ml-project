# machine-learning-austin-housing-complete-ml-project
Complete ML project using the Austin Housing dataset with EDA, feature engineering, PCA/LDA, clustering (HDBSCAN &amp; GMM), regression/classification models, regularization, MLP, and full model evaluation. Includes notebook, plots, and results.


📌 Project Overview

This project explores and models real-estate data to understand the relationships between features and predict housing prices.
It includes:

Data cleaning and preprocessing

Exploratory Data Analysis (EDA)

Feature engineering

Feature Selection (Lasso, Ridge)

Feature Extraction (PCA)

Dimensionality Reduction

Clustering (HDBSCAN, GMM)

Supervised Learning (Regression + Classification)

Neural Networks (MLP)

Model evaluation and comparison

📊 Dataset

Austin Housing Dataset

Cleaned and encoded

Includes price, location details, size, condition, and categorical attributes

Final processed dataset used for training multiple ML models
